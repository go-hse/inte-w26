Listen: ul, ol und dl

ul ungeordnete Liste   ol geordnete Liste   li Listeneintrag   dl · dt · dd Beschreibungsliste   a Link

Selektor ausprobieren:

1. Ungeordnete Liste: ul

Für Aufzählungen, bei denen die Reihenfolge keine Rolle spielt. Jeder Eintrag steht in einem li; das Aufzählungszeichen erzeugt der Browser. Screenreader kündigen eine Liste mit der Anzahl ihrer Einträge an – die Strukturansicht zeigt diese Zahl ebenfalls.

  • HTML – Struktur und Bedeutung
  • CSS – Darstellung
  • JavaScript – Verhalten

2. Geordnete Liste: ol

Für Schritte oder Ranglisten, bei denen die Reihenfolge zählt. Die Nummern stehen nicht im Quelltext – der Browser zählt selbst. Ein Eintrag mehr oder weniger, und die Nummerierung stimmt trotzdem. Faustregel: Ändert das Vertauschen zweier Einträge die Bedeutung? Dann ol.

  1. Ordner für das Projekt anlegen
  2. index.html mit dem Grundgerüst erstellen
  3. Seite im Browser öffnen
  4. Quelltext mit dem W3C-Validator prüfen

3. Zählung steuern: start, reversed, type

start setzt die Zählung fort, wenn Text eine Liste unterbricht. reversed zählt rückwärts, type wählt Buchstaben oder römische Zahlen. Alle drei beschreiben die Bedeutung der Zählung – Farbe oder Form der Zeichen regelt CSS.

  1. DNS-Anfrage: Domain in IP-Adresse auflösen
  2. TCP-Verbindung aufbauen
  3. HTTP-Request senden

… jetzt arbeitet der Server …

  1. HTTP-Response empfangen
  2. HTML parsen und Seite darstellen

Countdown bis zur Abgabe:

  1. Validator meldet keine Fehler
  2. Quelltext ist eingerückt und kommentiert
  3. Abgeben

Antwortoptionen einer ARS-Frage:

  1. HTML
  2. CSS
  3. JavaScript

4. Verschachtelte Listen

Eine Unterliste steht innerhalb eines li, direkt hinter dem Text des übergeordneten Eintrags. ul und ol lassen sich dabei beliebig mischen.

  • HTML5

      1. Listen

    • Canvas und Video

Häufiger Fehler – die innere Liste steht direkt im ul, nicht in einem li. Der Browser stellt das meist trotzdem eingerückt dar, der Validator meldet aber einen Fehler:

<ul>
  <li>HTML5</li>
  <ul>                       <!-- falsch: ul als direktes Kind von ul -->
    <li>Body-Elemente</li>
  </ul>
</ul>

5. Beschreibungsliste: dl, dt, dd

Für Paare aus Begriff und Beschreibung, etwa ein Glossar oder technische Daten. dt ist der Begriff, dd die Beschreibung. Ein Begriff darf mehrere Beschreibungen haben.

HTTP
Protokoll, mit dem Browser und Webserver Anfragen und Antworten austauschen
DNS
Übersetzt Domainnamen in IP-Adressen
URL
Adresse einer Ressource im Web
Beispiel: https://www.hs-esslingen.de/studium

6. Listen als Navigation: nav + ul + a

Menüs sind fast immer ungeordnete Listen von Links. Per CSS werden sie waagerecht und verlieren ihre Punkte – im Quelltext bleiben sie Listen. Ein Link kann auf eine Sprungmarke (#id) dieser Seite zeigen, auf ein anderes Dokument oder auf eine Sprungmarke in einem anderen Dokument.
