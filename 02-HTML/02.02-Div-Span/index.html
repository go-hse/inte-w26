Selektor ausprobieren:

1. Block-Elemente: div

Ein div beginnt in einer neuen Zeile und ist so breit wie der verfügbare Platz – auch wenn sein Inhalt kurz ist.

2. Inline-Elemente: span

Ein span fließt im Text mit und ist nur so breit wie sein Inhalt.

Dieser Absatz enthält ein span mitten im Satz. Auch ein zweites span bleibt in derselben Zeile, und bei Platzmangel bricht ein langes span mit viel Text einfach mit dem Satz um, statt einen eigenen Block zu bilden.

3. class: mehrfach vergeben und kombinierbar

Alle Elemente mit derselben Klasse bekommen per CSS denselben Stil. Ein Element darf mehrere Klassen haben (durch Leerzeichen getrennt) – die Stile werden kombiniert.

Block mit class="hinweis"
Block mit class="wichtig"
Block mit class="hinweis wichtig" – beide Stile

Klassen gibt es auch für Inline-Elemente: hinweis, wichtig und beides.

4. id: genau einmal im Dokument

Eine id darf nur einmal vorkommen. Sie dient als Sprungmarke (Link zu #kontakt) und für den gezielten Zugriff per CSS und JavaScript.
