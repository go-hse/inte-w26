Formulare: Was prüft der Browser, was wird gesendet?

input Formularfeld   name wird gesendet   label verknüpfte Beschriftung   fehlt Problem

Methode:
1. label und name

Nur Felder mit name werden gesendet. Das label beschriftet das Feld für Screenreader; ein Klick darauf setzt den Fokus ins Feld. Ein Platzhalter ersetzt kein label.

2. Eingabetypen

Der Typ bestimmt Tastatur (mobil), Bedienelement und Prüfung. Gesendet wird immer Text.

3. Auswahl

Zusammengehörige Optionen gruppiert ein eigenes fieldset mit legend. Radio-Buttons mit gleichem name bilden eine Gruppe – gesendet wird nur der gewählte Wert. Checkboxen senden nur, wenn sie angehakt sind; gleicher name ergibt mehrere Werte.

4. Validierung ohne JavaScript

Die Attribute prüft der Browser selbst. Die Werte sind absichtlich falsch – korrigieren Sie sie und beobachten Sie den Status.

5. Besondere Felder und Absenden

hidden wird unsichtbar mitgesendet, readonly ebenfalls. disabled wird nicht gesendet.
