Mauszeiger auf eine Datenzelle: zugehörige Kopfzellen werden markiert

1. Grundgerüst: table, tr, th, td

Eine Tabelle wird Zeile für Zeile aufgebaut: tr ist eine Zeile, darin stehen die Zellen. th ist eine Kopfzelle, td eine Datenzelle. Spalten gibt es im Quelltext nicht – sie ergeben sich aus der Position der Zellen. Tabellen sind für tabellarische Daten da, nicht für das Seitenlayout; das übernimmt CSS.

Achtung: Der Quelltext unter dem Beispiel wird aus dem DOM erzeugt. Dort steht ein tbody, obwohl es im HTML fehlt – der Browser ergänzt es beim Parsen selbst.

2. caption, thead, tbody, tfoot und scope

caption ist die Überschrift der Tabelle. thead, tbody und tfoot gliedern die Zeilen in Kopf, Rumpf und Fuß. scope="col" macht eine Kopfzelle zur Spaltenüberschrift, scope="row" zur Zeilenüberschrift – Screenreader lesen sie beim Navigieren durch die Zellen mit vor. Probieren Sie es mit dem Mauszeiger aus.

Auch per JavaScript ist die Gliederung nutzbar: tabelle.tBodies[0].rows liefert nur die Datenzeilen, tabelle.tFoot den Fuß. insertRow() fügt eine Zeile ein, insertCell() eine Zelle – allerdings immer ein td; eine Kopfzelle muss man mit createElement("th") anlegen.

3. Zellen verbinden: colspan und rowspan

colspan="2" streckt eine Zelle über zwei Spalten, rowspan="2" über zwei Zeilen. Der Platz, den sie belegt, fehlt den anderen Zeilen: Die zweite Zeile im Rumpf hat deshalb ein td weniger, die letzte nur noch eines. Schalten Sie oben das Raster ein, um die Position jeder Zelle zu sehen.
